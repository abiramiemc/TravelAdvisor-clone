# TravelAdvisor-clone
Excited to share my latest frontend project – a Tripadvisor Landing Page Clone built using HTML5 and CSS3.

This project helped me strengthen my understanding of modern web design, responsive layouts, Flexbox, CSS positioning, and clean UI development without using any frameworks or JavaScript.

🚀 Features
Responsive and modern homepage design
Navigation bar with search section
Hero banner with travel inspiration
Destination cards with attractive layouts
Hotel and travel recommendation sections
Hover effects and interactive UI elements
Clean and organized file structure
Mobile-friendly design using responsive CSS
🛠️ Technologies Used
HTML5
CSS3
Flexbox
Media Queries
📚 What I Learned
Creating responsive layouts
Building reusable UI sections
Improving CSS styling and positioning
Organizing frontend project structure
Writing clean and maintainable code

I built this project as part of my frontend web development practice to improve my HTML and CSS skills. Feedback and suggestions are always welcome!
